# PoliticalLeaderPortal

> Enterprise-level ASP.NET MVC 5 Content Management System (CMS) and Political Campaign Management Platform.

---

# Overview

PoliticalLeaderPortal is a comprehensive enterprise web application developed using **ASP.NET MVC 5**, **.NET Framework 4.8**, **Entity Framework Database First (EDMX)** and **SQL Server**.

The platform combines a public-facing political leader website with a powerful administrative CMS and campaign management system. It enables administrators to manage website content, media, public engagement, election campaign activities, voter operations, digital member cards, events, surveys, and many other organizational functions from a centralized dashboard.

The application follows a traditional MVC architecture with a Service Layer and ViewModel pattern to keep presentation, business logic, and data access responsibilities well organized.
